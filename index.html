ℹ️ Sobre o Projeto

A Biblioteca Digital Acessível foi desenvolvida para reunir materiais educativos em uma interface previsível, limpa e fácil de navegar.

O layout evita excesso de estímulos visuais, utiliza alto contraste, tipografia legível e organização clara por categorias para atender diferentes perfis de estudantes.
